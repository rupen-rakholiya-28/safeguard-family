# Privacy Policy — SafeGuard Family

**Last Updated:** May 2026

## Overview

SafeGuard Family ("we", "us", "our") is a consent-first child safety platform that enables transparent family monitoring with explicit user consent.

## Data We Collect

### Account Data
- Email address (for authentication)
- Display name (for family identification)
- Encrypted password (never stored in plain text)

### Device Data
- Device model and OS version (for compatibility)
- Battery level (for device status)
- Device identifier (for family linking)

### Usage Data (Only with Consent)
- **Screen time**: Total daily device usage duration
- **App usage**: App names and usage duration (aggregated signals only)
- **Location**: Device coordinates (only when location consent is granted)

## Data We Do NOT Collect
- ❌ Message content, chat logs, or communications
- ❌ Photos, videos, or media files
- ❌ Call logs or contact lists
- ❌ Browsing history content
- ❌ Keystroke data or screen recordings
- ❌ Audio or video recordings
- ❌ Any biometric data

## How We Use Data

All collected data is used solely to:
1. Provide screen time and usage insights to linked parents
2. Share location with linked parents (when consented)
3. Deliver safety alerts to parents
4. Maintain device connectivity status

## Data Sharing

- Data is shared **only** with the parent account linked through a family invite code
- We do **not** sell, rent, or share data with any third parties
- We do **not** use data for advertising purposes
- We do **not** use data for AI model training

## Consent & Control

- **Granular consent**: Each monitoring feature requires separate explicit approval
- **Revocable**: Any consent can be revoked at any time by the parent
- **Transparent**: A persistent notification always shows what is being monitored
- **Auditable**: All consent changes are logged with timestamps

## Data Security

- All data transmitted via HTTPS/TLS encryption
- Authentication tokens stored in encrypted device storage
- Server-side data encrypted at rest
- JWT-based stateless authentication

## Data Retention

- Usage data is retained for 30 days
- Account data is retained until account deletion
- All data is deleted upon family disconnection
- Users can request complete data deletion at any time

## Children's Privacy

- This app is designed for use by children (13+) with parental oversight
- No data is collected without explicit consent
- No advertising or in-app purchases
- Compliant with COPPA and applicable child privacy regulations

## Changes to This Policy

We will notify users of any material changes to this privacy policy through the app and via email.

## Contact

For privacy inquiries, data deletion requests, or concerns:
- Email: privacy@safeguardfamily.com

## Your Rights

You have the right to:
- Access your personal data
- Request data deletion
- Revoke monitoring consents
- Disconnect from a family group
- Export your data
